Baseline: stable tag v2026.23, commit c0f40a2e78d81a7474628847727644fc0c56f558.
The upstream Git history is retained locally. The `upstream` remote points to SourceGit.

GitGator-specific modifications are also offered under MIT.

THIRD-PARTY-LICENSES.md and the pinned AvaloniaEdit submodule retain their notices.
The app icon and orange gator branding are GitGator-specific. Other inherited artwork
and resources retain their original attribution and third-party notices.
The SourceGit C# namespace is intentionally retained to ease upstream maintenance.

The original README and GitHub workflows are preserved under docs/upstream.
Archived workflows and build/scripts are upstream references, not GitGator release tooling.
GitGator has no publishing workflow. SourceGit update detection is disabled by default.
